# GRU持续负进展的根因验证

**根因判断：直接产生持续负进展偏好的环节是后继价值打分；在这组被比较的候选中，不是一步后继近似或即时安全惩罚使后退获胜。已确认部分状态的价值承诺与冻结GRU实际续行回报失配，另有单步换动作仍回到失败续行的策略陷阱。但历史训练的上游主因没有闭合：延长时限未纠正原71处排序失配；唯一匹配训练中，补上训练平滑仅将失配57降到55，成功201降到198、碰撞6升到8，验证不通过。不得将平滑、时限、数据覆盖或部分可观测性任一项包装为已确认的唯一根因。**

本轮没有开发新算法，没有方法级进展。以下已完成结果不因后续训练结果改变。

## 1. 观察对象与有效性

- 分支：research/gru-root-cause-20261011；冻结协议见protocol.json、upstream-protocol.json、causal-training-protocol.json。
- 名义GRU：seed61，1754857参数；512条成功ORCA示范、20轮IL、2000次RL。这里不是历史10000次训练/3000例评测模型。
- 原始权重：research/recovery-duration/artifacts/nominal.pth；SHA256为879c612fcea61a7e39bdef6506b4eb141b6eecdf0de46eda39ad8525acd8ee2c。
- 源码基点6def8a8，终止评分修复400cff3。本轮未修改crowd_nav或crowd_sim源文件，也未修改原项目的代码、配置或权重；独立工作树的Git提交正常更新共享仓库元数据。
- 原240例：六场景各case100..139。保留原1949状态与164反事实起点；修复后重新获得1957个采样状态，不能把旧完整结局当新结局。
- 当前和候选后继先取最近5人；安全计算用全体行人。5人限制属于现有输入设计，不再作为未修复的“顺序截断错误”处理。
- 80个原动作，T24合法历史，测试平滑0.3、安全净距0.2、风险系数0.8、时限25；均保持不变。
- preflight.json确认三个原生案例的评分帮助函数与正式策略选择/执行一致，两次完整重放逐位一致。164/164旧起点在修复后的自然轨迹中仍可按相同前缀到达。
- robot.visible=false，表示机器人不进入行人的观测，而不是机器人看不到人群。机器人得到当前全体行人的位置/速度，价值编码器仅取最近5人；人群运动不响应机器人，故可以使用保存的人群轨迹进行同起点配对。50秒扩展轨迹逐帧验证了原103帧前缀；完整仿真状态只用于离线诊断。不得把本实验解释成双向社交让行。

## 3. 三层对照定位错误环节

对每个固定起点使用同一个负进展首动作a-和同安全集合中进展最大的首动作a+：

    A(a) = r_pred + gamma * (1-terminal_pred) * V(history + predicted_next)
    B(a) = r_native + gamma * (1-terminal_native) * V(history + actual_next)
    C(a) = discounted actual return after forcing a once, then the same repaired GRU

gamma=0.99。B使用真实一步后继的合法观测字段，不给网络隐藏目标或未来轨迹。C保持起点、剩余时限、人群轨迹、平滑、安全和后续策略相同。

### 直接原因：价值项维持负进展

164/164对候选的A即时奖励相同，风险项均为0。当前选择不是因为前进候选被过滤或即时惩罚更高，而是V给负进展后继更高分。这个结论由实际评分分解直接确认，不靠轨迹猜测。

### 一步模型不是这组候选排序的主要来源

- 将行人预测位置、速度分别或同时换为真实一步状态，最终A到B的排序反转为0/164。
- 单动作A/B价值绝对差均值0.000918；这不表示CV完全准确，最大行人一步位置偏差达到0.155米。
- 6个起点的原生即时奖励与预测奖励不同，源于扫掠净距和终点净距的discomfort口径差异；没有一例因此反转这对候选的排序。
- 所以支持的是“真实一步替换未纠正本组排序”，不是“整个后继模型没有误差”。

### 价值估计失配与连续策略缺陷并存

| C的实际比较 | 起点数 | 实际含义 |
|---|---:|---|
| 前进回报更高 | 71 | 与B偏好负进展相反 |
| 负进展回报更高 | 49 | 对照前进不是普遍正确选择 |
| 回报相同 | 44 | 不能据排序差声称任务损失 |

71例中，59例是两边都成功但前进更快，6例是救回超时，6例是两边都超时但回报不同。前进一步也破坏6个原成功，均在large_square。两臂均124/164成功、40超时、0接触，净救回为0。负进展在部分固定选择对上确有任务优势，但这不等于已证明物理上只能后退避让。

这里“排序错误”是固定真实世界、指定首动作对的实现回报失配，不是对任意隐藏世界条件期望价值的理论反证。

### 更深的限制：失败续行使首动作监督退化

21例两边均超时且回报相同；21/21条对照沿途非终止奖励均为0，其回报精确等于：

    -0.5 * 0.99 ** (remaining_steps - 1)

因此，在这两种首动作之后都交回同一个失败策略时，MC标签不能区分其路径质量。其中14例已有相同物理起点、原安全约束下连续控制成功且无接触的保存轨迹。这里只复用这些轨迹作为存在性反例，不重跑旧控制器，不将旧完整实验结局当修复后的方法性能。

14例索引见statistics.json中的policy_trap_with_saved_safe_alternative。该事实证明“改这一个前进首动作然后交回GRU”不足以解决这些案例；不证明其余78个首动作均没有单步改进机会，也不证明某种恢复算法成立。

这21组是本轮固定部署策略续行的真实标签，不是恢复出的原训练回放标签。原训练使用50秒、探索行为且没有测试平滑/过滤；历史RL回放tokens未保存。不能将本轮的标签退化直接写成“已经证明原训练因这21组常数标签学错”。

## 4. 上游契约的单因素区分

以下均保持第一个实际执行动作不变，只改后续一个因素；统计对象是164个固定起点的selected分支，不是240例重新开始的算法SR。

| 后续契约 | 原71处失配被消除 | 全164处剩余失配 | selected成功 | 相对原C救回/破坏 | 接触 |
|---|---:|---:|---:|---:|---:|
| 原部署 | — | 71 | 124 | — | 0 |
| 仅时限25到50 | 0 | 72 | 131 | 7 / 0 | 0 |
| 仅关闭平滑 | 31 | 66 | 127 | 16 / 13 | 0 |
| 仅关闭过滤与风险消费 | 3 | 72 | 124 | 2 / 2 | 1 |
| 仅epsilon=0.05，4个配对draw | 11 | 84 | 118.25 | 4 / 9.75 | 1.75 |

关闭平滑消除31处旧失配，但产生26处新失配。它改变整个后续控制映射，不等于训练因果，也不是安全改善方案。关闭过滤产生真实接触，不能拿其低成本称收益。epsilon探针仍保留测试平滑、过滤与25秒时限，不能冒充完整复现原训练行为策略；四个draw不是四个独立场景。

epsilon行的成功、救回、破坏和接触是按四个draw平均后的等效案例数，实际selected分支共656次续行，成功473次、接触7次。其“剩余失配”按各起点四draw平均回报判断，样本很少，不构成期望价值精确估计。该有限探针不支持“加回一点探索即可兑现主要价值承诺”，也不能据此否定历史行为策略错配对学习的影响。

### 时限差异的准确结论

训练50秒、测试25秒属实，网络无显式剩余时间输入。延长时限可救回7/40个selected超时，但仍有33例到50秒超时，且33例B预测均为正，其B减50秒实际回报的中位差为0.7156。没有一处原71处排序失配被长时限纠正。

因此，时限是部分结局的因果因素，但不能充分解释主要排序失配。不能倒推“训练50秒导致了全部错误”，也不能声称已排除训练时钟影响。

## 5. 实际学习过程，而非配置文件名义预算

原训练入口是research/recovery-duration/run.py，不是通用训练入口配置中写着的名义10000次。

| 环节 | 实际事实 | 能支持什么，不能支持什么 |
|---|---|---|
| IL | 512成功ORCA轨迹、26030帧、20轮、2040更新 | 初始化主要由成功轨迹监督；不是失败状态全覆盖 |
| RL | 2000次、每例4更新、batch256、Adam1e-5、回放1024例 | 当前模型真实预算；不冒充正式大预算复现 |
| 标签 | 当前动作前历史，向后MC回报，无最终bootstrap | 学的是收集行为的实现回报，不是成对候选排序目标 |
| 行为 | epsilon0.3到0.05；训练不平滑、不安全过滤 | 与确定性、平滑、过滤的部署续行不同；源码差异不自动构成根因 |
| 场景 | 训练circle、5人、半径4；测试六场景5到20人 | 存在分布差异；尚未通过单因素训练确认其因果份额 |

### 一个已经排除的过强解释

## 6. 唯一一次匹配因果训练

两臂使用相同IL权重与512示范回放、seed61、2000次RL、相同MC目标/优化器/80动作/人群/50秒时限；共享终止评分修复。唯一变量是训练阶段所有动作（包含探索）是否做0.3平滑。测试均使用原0.3平滑、0.2过滤、0.8风险、25秒时限。

固定164起点仍比较原先同一对实际首动作，但B使用新权重、C使用该新权重自己的GRU续行，不将旧C当新模型真实价值。新模型未自然到达的旧起点单独标记。

预注册支持标准：相对新匹配控制，B/C双向严格失配减少至少20%，240例少至少4个超时，无额外接触。单seed开发诊断，不是论文确认。

在任何匹配闭环结果产生之前，acfce1f补充明确“不新增原生碰撞”也作为安全条件；这没有改变训练、参数或案例。

具体反例baseline_circle/115/t64：机器人已在(-0.439,5.525)，目标(0,4)；负进展-0.047米、前进+0.162米；两动作实际一步净距1.481/1.376米。A差0.01994，B差0.01994；两边交回GRU都超时，延长50秒和关闭平滑也未救回；保存的连续安全控制可1.5秒到达。该案例仅5人，不能用“第6个危险行人未输入”解释。它是明确的价值/连续控制缺陷证据，不是已确认的隐藏意图或训练覆盖根因。

## 8. 六个强制问题的当前回答

1. **直接原因：** 原安全集合内即时任务奖励同值，后继价值更偏好负进展；风险项不参与这164对的差别。
2. **深层原因：** 已确认价值排序与实际冻结策略续行失配、以及部分失败续行的MC标签退化。尚未确认哪个上游学习因素主要使网络形成该价值形状；不能把MC策略差异、场景分布差异或缺时钟输入任一项未经干预指定为唯一根因。
3. **因果证据：** A/B替换不改排序；长时限仅救回7/40超时；平滑匹配训练没有修复主问题，且破坏28个原成功。原71例中真正的单首动作救回6例、破坏6例，不能把71例全叫可修复失败。匹配训练没有确认上游主因，不能借其已完成掩盖这一缺口。
4. **规律：** 持续、全候选安全时的负进展集中于超时；单次后退不是错误判据。规则、覆盖、反例见第7节。
5. **研究分类：** 工程终止评分已公共修正；剩余样本内价值失配及连续策略陷阱属于算法/学习限制。部分可观测性与历史训练覆盖的实际份额未确认。
6. **算法意义：** 缺的是对“当前首动作的价值承诺能否被后续同一策略兑现”的可靠约束，以及跨连续动作脱困的可辨别监督；这只是能力缺口，不构成新机制或创新性成立的声明。

剩余解释不是泛泛的“多因素可能”，而是三个明确、可定位的缺口：

1. **训练支持与外推。** 原生训练仅circle5/radius4，测试square/10到20人/半径6；历史RL回放没有保存，无法从现有日志确认失败历史是否受到有效MC监督。5人案例也失败，故不能将全部问题归于新增行人数量。
2. **评价策略与监督目标。** MC标签来自回放中的历史探索行为、无平滑/过滤及50秒目标；部署是确定性、平滑/过滤、25秒续行。源码确认目标语义不同，但本轮没有隔离“只改变MC评价策略”的训练效应；5%探索探针不是其充分替代。
3. **输入别名。** 价值输入是T24/最近5人的合法观测，无显式剩余时间、全人群或人类隐藏目标。尚未证明当前失败必须依赖这些缺失量；已有5人、宽净距的反例阻止把问题全部归于截断/危险感知。

本轮主科学裁决：**INCONCLUSIVE——上游主要训练成因尚未确认。** 直接价值/续行失配及局部MC标签退化已确认，但不能把它们改名为已验证的历史训练根因。

### 唯一优先下一实验，不在本轮追加执行

**主研究决策HOLD：暂停新算法设计，缺的一项关键证据是“单一原生训练场景覆盖是否足以造成该价值外推错误”的单变量训练对照。** 本轮允许的唯一针对性训练已经用于平滑，不擅自追加第二训练因素。

唯一建议：从同一IL权重、相同RL随机设置开始，控制仍训练circle5/radius4；处理组只把训练场景采样器改为当前已有六个原生配置的均衡采样。两组保持相同总2000例、奖励、动作、历史、过滤/平滑契约、50秒训练时限、MC监督和优化预算；不加入新的场景，不修改既有原生场景参数或评价难度，不改输入。处理组会接触原先训练未覆盖的较密/不同几何场景，这正是被检验的训练分布因素。评测仍固定240例与164对，并报告每一格，不只取平均。

该实验只隔离“原生训练分布覆盖”这一因素，不将人数、几何或目标坐标中的某一项另行归因。若排序失配减少至少20%、实际失败减少至少4/240且安全不退步，进入公共训练覆盖修复（FIX），不算算法创新；否则否决“该预算内单靠覆盖即可修复”的候选（KILL），把监督策略/输入别名剩余证据交外部科研审查，不自动再开训练。预计本机两臂并行约40到60分钟，能够改变是否需要先修基线再谈算法的决策。

这不是声称下一次实验一定找到唯一根因。它是目前唯一推荐投入的区分性实验，优先分开“覆盖不足”与另两类解释；其阴性结果不等于输入信息或价值学习理论已被否定。
